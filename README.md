Closures in my code (Замыкания в моем коде)
Замыкания были применены в функциях memoize и counter. В функции memoize замыкание позволяет сохранять постоянную ссылку на объект cache между вызовами обернутой функции, при этом инкапсулируя саму структуру кэша внутри внешней функции. В функции counter замыкание удерживает приватную переменную count, защищая её от прямого изменения извне и предоставляя безопасный и контролируемый интерфейс для управления через методы inc, dec и геттер value. Это механизм работает благодаря тому, что возвращаемые функции сохраняют доступ к лексическому окружению своего создания даже после завершения выполнения родительской функции.
